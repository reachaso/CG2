# ロードマップ: タコの墨撃ちレールシューティング

## 1. プロジェクト概要
本作は『Let's GO ISLAND 3D』を参考にした、**レールシューティングゲーム**です。
プレイヤーはタコとなり、自動で進むルート（レール）に沿って移動しながら、迫りくる敵を倒していきます。

### コア仕様
- **ジャンル**: レールシューティング（ガンシューティング）
- **プレイ人数**: シングルプレイ専用
- **プレイヤーキャラ**: タコ
- **攻撃方法**: カーソル（照準）操作による射撃。既存の `WaterBullet` を再利用し、将来的に「黒い墨」の表現へとブラッシュアップする。現状はダメージのみの仕様とする。
- **敵キャラクター**: 船（水上）、他の魚、サメ（水中・水上）
- **ステージ構成**: 水上 → 水中 → 水上へとシームレス（または演出を挟んで）に変化するダイナミックなステージ進行。
- **使用エンジン**: ChasoEngine

## 3. 基本運用ルール
- **4時間（1ユニット）ルール**: 日付ではなく「量」で管理する。すべてのタスクは最大4時間（4h）以下に分解する。5時間を超えるタスクは分解不足とみなす。
- **バッファルール**: 見積もりの2倍の時間が経過した時点で、そのタスクの実装アプローチを強制的に見直すか、仕様を簡略化（デスコープ）する。
- **タスク管理**: Markdown形式で `[ ] T-X: タスク名 (Xh)` としてMust/Shouldの優先度順に並べる。
